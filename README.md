# Personal Portfolio Website

A personal portfolio website created by Ayush Jha, a B.Tech CSE Core student at JECRC University.

## Features
- Home, About, Education, Skills, Projects and Contact sections
- Project search and filtering
- Light and dark mode
- API-based chatbot to answer questions about the portfolio
- Responsive website design

## Projects
1. Python Programs Collection
2. Messy Python Code Improvement
3. Bug Fixing Using Cursor AI
4. Interactive Quiz Application
5. Book Reading List Application

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js API endpoint
- Groq API for chatbot responses
